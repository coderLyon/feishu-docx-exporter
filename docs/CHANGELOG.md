# 更新日志

本项目记录各版本的功能变更与问题修复。版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)；`0.x` 为开发迭代阶段，`1.0.0` 起为正式版本。

---

## [1.2.1] - 2026-10-19

### 修复

- **列表编号分组**：改为按飞书 `seq` 字段判定。`seq === '1'` 表示新列表开始，
  `auto` 表示续编号。此前只要中间隔了普通段落就重开（3.4 编号被拆断），
  或反过来把两个独立列表粘成一个（7.3 编号被连续）。
- **样式覆盖补齐**：列表（有序/无序）、待办、标注块正文、附件各增加独立 Word 样式，
  可在样式面板中分类调整；此前它们都挂在「正文」样式上。

### 新增

- `src/core/render/list-instance.js`：列表实例判定抽为纯函数。
- `tools/test-list-numbering.mjs`：覆盖「说明段落不打断」「seq=1 重开」「块级元素打断」三类场景，
  已纳入 `npm test`。

### 验证

- PDF 核对：3.4 编号 1–8 连续；7.x 各列表均从 1 重新开始。
- 样式使用统计：FdeListOrdered 68 / FdeListBullet 8 / FdeTodo 3 / FdeCallout 1 / FdeAttachment 1。
- `npm test`：结构断言 17 项 + 列表规则 4 项全部通过。

## [1.2.0] - 2026-10-19

稳定版。功能与默认行为已固定，后续版本以缺陷修复为主。

### 变更

- **内嵌表格默认改为「导出为图片」**，选项顺序调整为：图片 → 可编辑表格 → Excel 对象。
  图片方式版式最忠实、不依赖浏览器调试接口，也不受文档「禁止复制」限制；
  需要编辑能力时再手动切换。
- **有序列表编号不再被普通段落打断**：列表项之间的补充说明段落（`text` 块）此前会结束列表，
  导致后续条目从 1 重新编号；现在仅标题、表格、代码块、引用、图片等块级元素会开启新列表。

### 修复

- 修复 3.4 等章节中列表编号重复（1、2、3 之后又从 1 开始）的问题。

### 验证

- 全文编号扫描：3.4 编号连续（1–8），其余列表均在标题或块级元素处正常重开。
- 默认图片模式离线渲染：不生成 Excel 对象，降级项 12 条（均为无网络环境的预期项）。
- `npm test` 17 项断言通过。
- 面板选项顺序与默认值已在构建产物中确认。

## [1.0.0] - 2026-10-19

首个正式版本。相对 0.x 系列，本次统一了标题编号机制、输出样式与文档结构。

### 新增

- **标题自动编号**：标题编号改由 Word 的 `numbering` 维护。在 Word 中插入或删除标题后，后续编号自动重排；原有手工编号不再写入正文。
- **内嵌表格导出为 Excel 对象**：导出结果中的内嵌电子表格为 `Excel.Sheet.12` 嵌入对象，显示整表预览，双击进入 Excel 编辑，保留单元格底色、字号、合并与数字格式。
- **多维表格**：读取视图数据并渲染为 Word 原生表格，表头灰底、跨页重复。
- **代码块语法着色**：按 `language` 字段对字符串、注释、关键字与数字着色，配色随背景亮度切换。
- **附件卡片**：附件渲染为居中卡片，包含文件类型徽标、文件名、大小与操作提示，双击可打开原文件。
- **对比度保护**：对带背景色的块自动校正背景亮度，避免打印时出现深底深字。
- **宽表横向页**：面板提供开关，默认关闭，保持全文纸张方向一致。

### 变更

- 无序列表统一使用小圆点，缩进由 720/1440/2160 调整为 360/720/1080，悬挂 240。
- 附件大小上限由 20 MB 调整为 200 MB；大于 4 MB 的嵌入对象不再二次压缩。
- 图片与附件改为并发采集与下载，缩短整体导出耗时。

### 修复

- 修复导出文件扩展名为 `.zip` 的问题（重打包时 MIME 类型缺失）。
- 修复标题编号层级偏移一级、导致一级标题套用二级样式的问题。
- 修复内嵌表格读取时目标块已被虚拟列表卸载、导致读取失败的问题。
- 修复内嵌表格按块 ID 匹配时取到错误表格的问题（块 ID 由虚拟列表动态分配，改为按文档顺序索引）。
- 修复附件嵌入失败导致导出中断的问题。
- 修复同一文档中横向页与竖向页混排的问题。

### 已知限制

- 内嵌表格的单元格内容依赖浏览器调试接口读取，导出时该标签页不可同时开启开发者工具。
- 设为「禁止复制」的文档无法读取表格数据，将回退为图片。
- 多维表格中的人员、附件等字段以文本形式呈现。
